# 0033 · Mulligan partiel

> Décision consignée le 15 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

La décision 0032 fixe la main de départ à 5 cartes (204.1.7) sans fixer le mulligan, laissé en discussion pour la section 204.2. Dans toutes les options présentées, les deux joueurs décident en même temps, sans voir le choix de l'autre. Question ouverte d'origine : aucune.

## Options envisagées

Mode du mulligan :

| Option | Pour | Contre |
| --- | --- | --- |
| A · Mulligan complet une fois : les 5 cartes remises, deck mélangé, 5 nouvelles cartes piochées ; règle du prototype | Non débattu. | Tout ou rien : le joueur perd aussi les cartes qu'il voulait garder. |
| B · Mulligan partiel une fois : le joueur choisit les cartes à remettre, autant qu'il veut, et en pioche autant ; modèle de Hearthstone ; option recommandée | Le joueur garde sa carte clé ; réduit la chance au départ sans règle de plus ; sert le public compétitif. | Non débattu. |

Ordre du mulligan partiel :

| Option | Pour | Contre |
| --- | --- | --- |
| A · Remettre les cartes écartées, mélanger, puis piocher | Non débattu. | Le joueur peut repiocher une carte qu'il vient d'écarter. |
| B · Piocher d'abord les remplaçantes, puis remettre les cartes écartées et mélanger ; modèle de Hearthstone ; option recommandée | Le joueur ne repioche jamais une carte qu'il vient d'écarter. | Non débattu. |

## Choix

Le créateur a retenu l'option B, recommandée, pour le mode, et l'option B, recommandée, pour l'ordre, le 15 octobre 2026. Raison principale : le mulligan partiel réduit la chance au départ sans règle de plus, ce qui sert le public compétitif.
