# 0013 · Types de cartes

Remplacée en partie par 0138 (perspective du type Trap close).

> Décision consignée le 15 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

La section 202.2 Types de cartes était vide : les types des cartes du deck n'étaient pas consignés. Le prototype comptait trois types, Unit, Building et Spell, et le créateur envisage un type Trap pour un développement futur, sans savoir encore à quoi il ressemblerait. Question ouverte d'origine : aucune.

## Options envisagées

| Option | Pour | Contre |
| --- | --- | --- |
| A · Trois types : Unit, Building, Spell, comme le prototype | Non débattu. | Non débattu. |
| B · Ajouter Gear, un équipement attaché qui n'occupe pas de case, comme dans Riftbound | Non débattu. | Non débattu. |
| C · Ajouter Trap | Non débattu. | Non débattu. |

## Choix

Le créateur a retenu l'option A complétée par Gear le 15 octobre 2026 : une carte de deck est une Unit, un Building, un Spell ou un Gear. L'option C n'est pas retenue dans les règles : le type Trap est réservé à un développement futur, sans forme définie, en lien avec [Q-002](../02-questions-ouvertes.md).

## Conséquences sur les règles

- Chapitre 202 : 202.2.1, 202.2.2, 202.2.3, 202.2.4, 202.2.5, 202.2.6 et 202.2.7 créés.
- Termes ajoutés au glossaire : Building, Carte, Gear, Spell, Unit.
- Charte, §2 : Gear ajouté aux termes qui restent en anglais avec majuscule.
- Question ouverte Q-002 : contexte ajouté sur le type Trap.
