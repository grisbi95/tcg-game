# Glossaire

> Rôle : vocabulaire unique de tous les documents. Un terme, une définition, une ligne, par ordre alphabétique. Statut : en cours d'écriture. Créé le 15 octobre 2026.

| Terme | Définition | Statut |
| --- | --- | --- |
| Abandonner | Pour un joueur, renoncer à poursuivre la partie, qu'il perd alors ; voir 201.1.3a, 206.4.6a, 209.2.5, 209.2.6 et 209.2.7. | |
| Action normale | Action d'une de ses pièces qu'un joueur fait au plus une fois par tour ; le détail est au chapitre 205 ; voir 204.4.5, 204.4.6, 208.1.10 et 208.1.11. | |
| Action (vitesse) | Vitesse d'un Spell que son joueur n'annonce que pendant sa phase principale, quand la pile est vide, sans lien avec l'action normale ; voir 207.1.2, 207.1.3 et 207.1.4. | |
| Adjacent | Se dit de deux cases qui partagent un côté, jamais en diagonale ; voir 205.2.5 et 210.2.1. | |
| Adversaire | Pour un joueur, l'autre joueur de la partie ; voir 201.1.3a, 204.5.2, 207.1.6, 208.2.4 et 208.4.7. | |
| Allié | Se dit d'une pièce que contrôle le joueur concerné ; voir 205.1.7 et 205.4.5. | |
| Annoncer | Déclarer une action, qui s'ajoute au sommet de la pile en attendant d'être résolue ; voir 203.3.2, 208.1.1, 208.1.2, 208.1.3, 208.1.4, 208.1.5 et 208.4.1. | |
| Appartenir | Relation d'une carte avec le joueur dont le deck ou le Hero la fournit, d'un effet déclenché avec le joueur à qui appartient la carte ou le jeton qui porte cet effet, ou d'un jeton avec le joueur à qui appartient l'entrée de la pile qui l'a créé ; voir 201.5.1, 201.5.3, 201.5.4, 207.3.4 et 207.3.4a. | |
| Arrivée | Mot-clé de déclencheur dont l'effet se déclenche quand la pièce qui le porte arrive sur le plateau ; voir 210.3.1, 210.3.1a, 210.3.1b, 210.3.1c et 202.4.13a. | |
| Assaut | Mot-clé de combat à valeur X, qui donne à la pièce X de Force de plus quand elle attaque ; voir 210.4.1, 210.4.1a, 210.4.1b et 210.4.1c. | |
| Attacher | Lier un Gear à une pièce, qui porte alors ce Gear ; voir 202.2.6, 202.2.8, 207.2.8 et 208.1.5. | |
| Attaquant | Pièce qui attaque, dans un combat ; voir 206.1.1. | |
| Attaquer | Pour une pièce, engager un combat contre une pièce ennemie, réglé au chapitre 206 ; voir 205.1.6, 205.2.3 et 206.1.1. | |
| Aura | Effet statique dont le résultat dépend de la position des pièces sur le plateau ; voir Effet statique, 206.5.2, 206.5.3, 206.5.4 et 206.5.5. | |
| Avant-poste | Mot-clé de Building qui permet à son joueur de déployer une Unit sur une case adjacente à ce Building ; voir 210.2.1 et 210.2.1a. | |
| Building | Type de carte de deck, et pièce du plateau issue d'une carte de ce type ou jeton que désigne l'effet qui le crée ; voir 202.2.3, 202.4.8 et 202.4.11. | |
| Carte | Élément de jeu qui se trouve dans une zone. | |
| Case | Position du plateau. | |
| Cible | Pièce du plateau, case ou Spell de la pile qu'un effet vise, choisie quand l'entrée de la pile qui porte cet effet s'y ajoute ; voir 202.4.12, 207.5.1, 207.5.2, 207.5.3, 207.5.6, 207.5.11, 207.5.14 et 207.5.16. | |
| Cible légale | Cible qui remplit, au moment où l'entrée s'ajoute à la pile, les conditions que la carte pose à ses cibles et celles de la section 207.5 ; voir 207.5.8, 207.5.9 et 207.5.10. | |
| Colonne | Alignement de cases du plateau qui s'étend d'un joueur à l'autre. | |
| Combat | Affrontement d'un attaquant et d'un défenseur, réglé au chapitre 206 ; voir 206.1.1, 206.1.2, 206.2.1 et 206.4.2. | |
| Compteur de fatigue | Valeur propre à chaque joueur, qui augmente chaque fois qu'il doit piocher alors que son deck est vide et fixe les PV que perd alors son Hero ; voir 209.5.1, 209.5.2, 209.5.2a, 209.5.3, 209.5.4 et 209.5.4a. | |
| Condition de fin de partie | Condition, fixée par les règles du jeu, qui fait gagner, perdre ou finir la partie sur un nul ; voir 201.0.4, 201.1.2, 201.1.2a, 201.1.2b, 201.1.3a, 201.1.3c, 209.2.8a et 209.3.1. | |
| Contrecarrer | Effet qui fait qu'un Spell qui se trouve sur la pile n'a pas lieu ; voir 207.6.1, 207.6.2, 207.6.4 et 207.6.5. | |
| Contrôler | Relation d'un joueur avec chaque carte et chaque jeton qui lui appartiennent ; voir 201.5.2 et 201.5.2a. | |
| Coût | Valeur que porte toute carte de deck, et que porte aussi la carte Hero pour son pouvoir ; voir 202.1.2, 202.3.13 et 203.3.2. | |
| Début du tour | Première partie du tour, qui précède la phase principale ; voir 204.3.8, 204.4.1, 208.4.10 et 208.4.11. | |
| Deck | Zone hors du plateau qui forme l'ensemble de cartes face cachée d'un joueur ; voir 201.3.1 et 201.4.1. | |
| Déclencher | Faire qu'un effet déclenché doive avoir lieu, pour un événement indiqué par le texte de cet effet ; voir 207.3.1, 208.4.2 et 208.4.4. | |
| Défausse | Zone hors du plateau qui rassemble les cartes d'un joueur mises au rebut. | |
| Défenseur | Pièce attaquée, dans un combat ; voir 206.1.2. | |
| Déplacement | Passage d'une pièce de sa case à une autre case ; voir 205.2.2 et 205.3.1. | |
| Déployer | Jouer une Unit ou un Building en le plaçant sur une case du plateau ; voir 205.1.1, 205.1.2 et 205.1.3. | |
| Dernier souffle | Mot-clé de déclencheur dont l'effet se déclenche quand la pièce qui le porte est détruite ; voir 210.3.2, 210.3.2a, 210.3.2b, 210.3.2c et 202.4.13a. | |
| Détaché | Se dit d'un Gear qui n'est plus attaché à une pièce, parce qu'il a été remplacé ou que sa pièce a quitté le plateau ; voir 202.2.12, 202.2.13, 207.2.9a, 207.2.9b et 207.4.8. | |
| Détruire | Envoyer une pièce dans la défausse du joueur à qui elle appartient ; pour un jeton, voir 202.4.3 ; voir 206.3.1, 206.3.2, 206.3.2a, 206.3.6 et 210.3.2. | |
| Durée | Mention du texte d'un effet qui fixe jusqu'à quand il dure, parmi « jusqu'à la fin du tour » et « tant que la pièce est en jeu » ; voir 207.4.1, 207.4.2, 207.4.3, 207.4.7, 207.4.7a, 207.4.7b, 207.4.8 et 207.4.10. | |
| Écart | Zone temporaire hors du plateau, propre à chaque joueur et face cachée, qui existe pendant le mulligan et accueille les cartes écartées ; voir 201.3.9, 201.3.10, 201.4.9, 204.2.10 et 204.2.11. | |
| Écarter | Choisir, pendant son mulligan, une carte de sa main à remettre dans son deck, la carte allant alors dans l'Écart ; voir 204.2.4, 204.2.6, 204.2.8 et 204.2.10. | |
| Échouer | Pour une action annoncée, ne pas avoir lieu à sa résolution ; voir 205.4.6. | |
| Effet | Instruction du texte d'une carte qui change l'état de la partie ou les règles qui s'y appliquent. | |
| Effet déclenché | Effet qui a lieu quand survient un événement indiqué par son texte ; voir 204.5.3, 207.3.1, 207.3.2, 207.3.3, 207.3.4, 207.3.4a, 207.3.5, 207.3.7a, 207.3.11, 207.3.11a, 208.3.2a, 208.4.2, 208.4.3, 208.4.4, 208.4.5, 208.4.6, 208.4.7, 208.4.8, 208.4.10, 208.4.11, 208.5.1a, 210.3.1b et 210.3.2a. | |
| Effet ponctuel | Effet qui n'est pas statique, dont le texte ne porte aucune durée et qui change l'état de la partie une fois ; voir 202.2.21, 207.4.9 et 207.4.6. | |
| Effet statique | Effet qui s'applique sans passer par la pile, tant que la pièce qui le porte est en jeu ; voir 207.2.1, 207.2.2, 207.2.3, 207.2.3a, 207.2.4, 207.2.5, 207.2.6, 207.2.7, 207.2.8, 207.2.9, 207.2.9a et 207.2.9b ; le Passif d'un Hero et l'aura en sont des cas ; voir 202.3.18 et 206.5.4. | |
| En jeu | État d'une pièce sur le plateau, ou d'une Source qui n'est ni dans la réserve ni dans la Fonte de son joueur ; voir 202.2.2, 202.2.3 et 203.5.4. | |
| Ennemi | Se dit d'une pièce que contrôle l'adversaire du joueur concerné ; voir 205.1.6 et 205.2.3. | |
| Entrée de la pile | Annonce ou effet déclenché qui se trouve sur la pile, et qui appartient au joueur qui a fait l'annonce ou, pour un effet déclenché, au joueur de 207.3.4 ou de 207.3.4a ; voir 201.3.7, 201.5.4, 202.4.6, 208.1.1 et 208.2.4. | |
| Essence | Ressource du jeu ; voir 203.1.1, 203.3.1 et 203.3.3. | |
| Exemplaire | Chacune des cartes qui portent le même nom ; voir 201.6.2. | |
| Fin du tour | Dernière partie du tour, qui commence quand le joueur actif termine son tour et précède le début du tour de son adversaire ; voir 204.4.7 et 204.5.3. | |
| Fonte | Emplacement propre à chaque joueur, qui accueille ses Sources recyclées ; voir 203.5.2, 203.5.3, 203.5.4 et 203.5.6. | |
| Force | Statistique de combat des Units et des Buildings ; voir 202.1.5, 202.1.6, 202.4.9, 206.2.2, 206.2.3 et 209.1.1. | |
| Force imprimée | Force que porte la carte d'une Unit ou d'un Building, ou que l'effet qui crée un jeton donne à ce jeton ; voir 202.1.5, 202.1.6, 209.1.1 et 209.1.1a. | |
| Garder sa main | Pour un joueur, n'écarter aucune carte de sa main pendant le mulligan, ce qui n'est pas un mulligan ; voir 204.2.12, 204.2.13 et 204.2.14. | |
| Gear | Type de carte de deck ; voir 202.2.6 et 202.2.7. | |
| Hero | Pièce du plateau qui représente un joueur et porte ses PV, et qui est aussi une carte hors du deck ; voir 202.3.2, 202.3.4 et 202.3.5. | |
| Incliner | Faire passer une Source de l'état redressé à l'état incliné ; voir 203.2.1. | |
| Invariant | Règle de la section Invariants d'un chapitre des règles complètes, dont l'identifiant a la forme 201.0.1, qu'aucune carte ne contredit ; voir 200.2.1a, 201.0.1, 201.0.2, 201.0.4, 203.0.1, 206.0.1 et 206.0.2. | |
| Jeton | Pièce du plateau qui ne provient d'aucune carte, est une Unit ou un Building avec une Force que désigne l'effet qui le crée, ne reçoit de cet effet ni effet ni mot-clé, peut en recevoir ensuite d'une autre source et ne se crée que par l'effet d'une entrée de la pile ; voir 201.5.2a, 201.5.4, 202.4.1, 202.4.2, 202.4.3, 202.4.4, 202.4.5, 202.4.5a, 202.4.6, 202.4.7, 202.4.8, 202.4.9, 202.4.10, 202.4.11, 202.4.12, 202.4.12a, 202.4.12b, 202.4.12c, 202.4.13, 202.4.13a, 207.3.4a, 207.3.7a, 207.3.11, 207.3.11a et 209.1.1a. | |
| Jouer | Utiliser une carte de sa main ; voir 204.4.3 et 207.1.6. | |
| Joueur | Personne qui prend part à une partie. | |
| Joueur actif | Joueur dont c'est le tour ; voir 204.4.2 et 208.4.6. | |
| Libre | Se dit d'une case qui ne contient aucune pièce ; voir 201.0.1, 202.4.12 et 202.4.12b. | |
| Limite de main | Nombre maximal de cartes qu'un joueur peut avoir en main ; voir 201.3.4, 201.3.5, 201.3.6, 201.3.6a et 205.1.10. | |
| Main | Zone hors du plateau qui contient les cartes qu'un joueur tient. | |
| Main de départ | Cartes qu'un joueur a en main après avoir pioché pendant la préparation ; voir 204.1.15 et 204.2.4. | |
| Mélanger | Mettre les cartes de son deck dans un ordre aléatoire ; voir 204.1.6 et 204.2.7. | |
| Modificateur | Bonus ou malus de la Force d'une pièce ; voir 206.2.3 et 206.5.1. | |
| Mot-clé | Terme du texte d'une carte dont la règle est au chapitre 210, et qui peut porter une valeur numérique que la carte précise ; voir 202.4.13, 202.4.13a, 210.1.1, 210.1.2 et 210.1.3. | |
| Mulligan | Remplacement, une seule fois, de cartes de sa main par des cartes de son deck ; voir 204.2.1, 204.2.4, 204.2.5 et 204.2.13. | |
| Partie | Affrontement qui oppose deux joueurs. | |
| Partie nulle | Issue d'une partie qui s'arrête sans vainqueur ; voir 201.1.2a, 201.1.2b, 209.2.8a et 209.3.1. | |
| Passer | Renoncer à répondre ; voir 208.2.2, 208.2.4 et 208.3.1. | |
| Passif | Effet statique d'un Hero ; voir Effet statique, 202.3.11 et 202.3.18. | |
| Payer | Fournir l'Essence qu'exige un coût ; voir 203.2.4, 203.3.1, 203.3.2 et 203.3.3. | |
| Pendule | Temps dont dispose chaque joueur pour toute la partie, qui ne tourne que quand les règles attendent une décision de lui ; voir 209.4.1, 209.4.2, 209.4.3 et 209.4.4. | |
| Phase principale | Phase du tour qui suit le début du tour, pendant laquelle le joueur actif agit ; voir 204.4.1, 204.4.2 et 208.4.11. | |
| Pièce | Élément qui occupe une case du plateau. | |
| Pile | Zone commune aux deux joueurs qui forme l'ensemble ordonné des annonces et des effets déclenchés en attente de résolution ; voir 201.3.7, 201.3.8, 201.4.7, 207.3.2 et le chapitre 208. | |
| Piocher | Faire passer la carte du dessus de son deck dans sa main ; voir 204.1.15, 204.2.5, 204.3.6 et 204.3.7. | |
| Plateau | Surface de jeu commune aux deux joueurs, divisée en cases. | |
| Pouvoir | Capacité d'un Hero que son joueur choisit d'utiliser ; voir 202.3.12, 202.3.13, 202.3.14, 202.3.15, 202.3.16 et 202.3.17. | |
| Premier joueur | Joueur qui joue le premier tour de la partie ; voir 204.3.4. | |
| Première rangée | Rangée du plateau la plus proche d'un joueur. | |
| Préparation | Période de la partie qui précède le premier tour et comprend la mise en place de la section 204.1 et le mulligan ; voir 204.1.9, 204.1.10 et 204.1.11. | |
| Priorité | Droit d'un joueur d'agir, soit d'annoncer pendant sa phase principale quand la pile est vide, soit de répondre ou de passer après un ajout à la pile ; voir 208.2.2, 208.2.4 et 208.5.1. | |
| PV | Points de vie d'un Hero ; voir 202.3.7 et 204.1.8. | |
| Rangée | Alignement de cases du plateau dont toutes les cases sont à la même distance de chaque joueur. | |
| Rangée centrale | Rangée 3 du plateau, à égale distance des deux joueurs ; voir 205.1.4. | |
| Réaction (vitesse) | Vitesse d'un Spell que son joueur peut annoncer pendant sa phase principale, quand la pile est vide, et aussi chaque fois qu'il peut répondre ; voir 207.1.2, 207.1.5, 207.1.6 et 208.2.3. | |
| Recycler | Faire quitter le jeu à une Source inclinée ; voir 203.2.2, 203.2.3, 203.2.6 et 203.2.7. | |
| Redresser | Faire passer une Source de l'état incliné à l'état redressé ; une Source dans cet état est dite redressée ; voir 203.2.1 et 204.1.17. | |
| Règle du jeu | Règle numérotée des règles complètes, par opposition au texte d'une carte ; voir 200.2.1 et 200.3.1b. | |
| Rempart | Mot-clé de combat à valeur X, qui donne à la pièce X de Force de plus quand elle défend ; voir 210.4.2, 210.4.2a, 210.4.2b et 210.4.2c. | |
| Répondre | Agir pendant le tour d'un autre joueur ou en réaction à une action ; voir 204.3.9, 208.2.3, 208.2.4 et 208.4.5. | |
| Réserve | Emplacement propre à chaque joueur, qui contient ses Sources qui ne sont pas encore entrées en jeu ; voir 203.5.1, 204.1.12 et 204.3.5. | |
| Résoudre | Faire avoir lieu une annonce ou un effet déclenché de la pile ; voir 208.3.1, 208.3.2 et 208.3.2a. | |
| Source | Élément d'un joueur qui produit l'Essence ; voir 203.1.2. | |
| Sous-règle | Règle dont l'identifiant ajoute une lettre à celui de la règle qu'elle précise ; voir 200.1.1. | |
| Spell | Type de carte de deck ; voir 202.2.5, 202.2.20, 202.2.21 et 207.1.1. | |
| Temps écoulé | État d'un joueur dont la pendule atteint 0 minute, qui perd alors la partie, sauf si le temps de son adversaire est écoulé en même temps, la partie étant alors nulle ; voir 201.1.2b, 201.1.3c, 206.4.6b, 209.2.8, 209.2.8a, 209.2.9 et 209.4.5. | |
| Texte | Énoncé que porte une carte, qui peut être vide ; voir 202.1.4 et 202.3.8. | |
| Tour | Période de la partie attribuée à un joueur ; voir le chapitre 204. | |
| Type | Catégorie d'une carte de deck, parmi celles de 202.2.1 ; voir 202.1.3. | |
| Unit | Type de carte de deck, et pièce du plateau issue d'une carte de ce type ou jeton que désigne l'effet qui le crée ; voir 202.2.2, 202.4.8 et 202.4.10. | |
| Vide | Se dit de la pile quand aucune annonce ni aucun effet déclenché n'y attend d'être résolu ; voir 208.1.7, 208.5.1 et 208.5.1a. | |
| Vitesse | Caractéristique que porte une carte Spell, Action ou Réaction, qui fixe les moments où son joueur peut l'annoncer ; voir 207.1.1 et 207.1.2. | |
| Zone | Emplacement où se trouvent des cartes, sur ou hors du plateau. | |
