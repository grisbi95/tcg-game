# 0194 · Réserve d'Essence publique

> Décision consignée le 18 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

La décision 0190 donne à un joueur une réserve d'Essence pendant son tour. Aucune règle ne dit si son montant est visible de l'adversaire, alors que 201.4.4 rend visible l'état redressé ou incliné des Sources. Question ouverte d'origine : Q-093, ouverte le 18 octobre 2026 et tranchée le même jour.

## Options envisagées

| Option | Pour | Contre |
| --- | --- | --- |
| A · Le montant est visible des deux joueurs | Recommandée à la présentation ; l'adversaire voit déjà l'état des Sources (201.4.4), donc le montant se déduit ; plus simple. | Aucun bluff sur le montant. |
| B · Le montant n'est visible que de son joueur | Garde une part de bluff. | L'adversaire doit compter les Sources inclinées pour le deviner. |

## Choix

Le créateur a retenu l'option A le 18 octobre 2026. L'option B est écartée. Raisons données : l'adversaire voit déjà l'état des Sources, donc le montant se déduit ; c'est plus simple ; c'est le choix de Riftbound.
