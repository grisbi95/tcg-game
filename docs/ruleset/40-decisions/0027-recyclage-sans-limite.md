# 0027 · Recyclage sans limite

> Décision consignée le 15 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

La décision 0021 permet de recycler une Source inclinée sans fixer combien de Sources un joueur peut recycler par tour. Question ouverte d'origine : Q-012, que cette décision tranche.

## Options envisagées

| Option | Pour | Contre |
| --- | --- | --- |
| A · Sans limite, option recommandée | Chaque Source recyclée coûte un tour de croissance, puisqu'un joueur n'en reçoit qu'une par tour, donc le recyclage se limite de lui-même ; il permet les retournements soudains retenus de Yu-Gi-Oh! (décision 0005). | Non débattu. |
| B · Une Source recyclée par tour, limite qu'un passif de Hero pourrait lever | Reste le correctif si le playtest montre des tours trop explosifs. | Non débattu. |

## Choix

Le créateur a retenu l'option A le 15 octobre 2026, en valeur PROVISOIRE à mesurer en playtest : nombre de Sources recyclées par tour, tours décisifs après un recyclage massif. Raison principale : le recyclage se limite de lui-même, chaque Source recyclée coûtant un tour de croissance, et il permet les retournements soudains (décision 0005).
