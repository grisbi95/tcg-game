# 0176 · Recycler une Source inclinée dans le même paiement

> Décision consignée le 16 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

203.2.1 permet d'incliner une Source redressée pour produire 1 Essence et 203.2.2 de recycler une Source inclinée pour produire 1 Essence, mais aucune règle ne dit si une Source inclinée pendant un paiement peut y être recyclée aussitôt. Question ouverte d'origine : Q-079.

## Options envisagées

| Option | Pour | Contre |
| --- | --- | --- |
| A · Seules les Sources déjà inclinées avant le paiement peuvent être recyclées dans ce paiement | Un joueur ne tire d'un coup au plus qu'une Essence par Source redressée ; les retournements soudains restent bornés. | Un joueur qui a 2 Sources redressées et aucune inclinée ne peut pas payer un coût de 4 Essence. |
| B · Une Source inclinée pendant le paiement peut y être recyclée aussitôt | Chaque Source en jeu vaut jusqu'à 2 Essence d'un coup, dans l'esprit de la décision 0027 (recyclage sans limite). | Retournements plus brutaux ; le coût maximal payable en un tour double presque. |

## Choix

Le créateur a retenu l'option B le 16 octobre 2026. L'option A est écartée : seules les Sources déjà inclinées avant le paiement peuvent être recyclées. Une Source inclinée pendant un paiement peut y être recyclée aussitôt, et chaque Source redressée peut donc produire jusqu'à 2 Essence d'un coup.

## Conséquences sur les règles

- Chapitre 203 : 203.2.6 et 203.2.7 créés, au statut ACTÉ. 203.2.1, 203.2.2, 203.2.4 et 203.4.2 non modifiés.
- Termes modifiés au glossaire, renvois seulement : Recycler, qui cite aussi 203.2.6 et 203.2.7. Les mesures de 203.4.2 (Sources recyclées par tour, tours décisifs après un recyclage massif) restent celles de la décision 0027.
- Question ouverte tranchée : Q-079.
