# 0234 · Renvoyer une pièce dans la main

> Décision consignée le 26 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

Des cartes du catalogue de playtest (Passeur, Reflux) renvoient une Unit ennemie dans la main de son joueur. Les règles ne décrivaient ce passage que pour un déploiement ou un Gear qui ne s'attache pas, et ne disaient rien du jeton, du Gear attaché ni de Dernier souffle. Question ouverte d'origine : Q-133.

## Options envisagées

| Option | Pour | Contre |
| --- | --- | --- |
| A · La carte revient dans la main, dans la défausse si la main est pleine ; le jeton cesse d'exister ; le Gear attaché va dans la défausse ; Dernier souffle ne se déclenche pas ; option recommandée par l'assistant | Le renvoi a toujours lieu ; même traitement que 205.1.10. | Un renvoi peut défausser la carte. |
| B · Même règle, mais pas de renvoi si la main est pleine | Aucune carte n'est défaussée par un renvoi. | La main de l'adversaire peut empêcher le renvoi. |

## Choix

Le créateur a retenu l'option A le 26 octobre 2026, conformément à la recommandation. L'option B est écartée. Un renvoi n'est pas une destruction.

- Q-133 tranchée, option A.
