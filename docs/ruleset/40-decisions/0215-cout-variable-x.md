# 0215 · Coût variable X

> Décision consignée le 26 octobre 2026. Statut : ACTÉ. Une décision ne se modifie jamais ; pour revenir dessus, une nouvelle décision la remplace et cette ligne reçoit « Remplacée par NNNN ».

## Contexte

Une carte du catalogue de playtest, un Spell de vitesse Action de coût X qui détruit une Unit ennemie ciblée de Force X ou moins, exige un coût variable. La règle 202.1.2 ne connaît qu'un coût porté par la carte ; le coût est payé à l'annonce (203.3.2) ; le recyclage permet un gros paiement (203.2.7) ; une carte du catalogue lit le coût d'un Spell sur la pile. Question ouverte d'origine : aucune.

## Options envisagées

| Option | Pour | Contre |
| --- | --- | --- |
| A · Coût X général | Fidèle à l'idée du créateur ; crée une décision d'investissement. | Une règle de coût de plus ; le coût d'une carte n'est plus lisible dans la main. |
| B · Plusieurs cartes à coût fixe | Aucune règle ne change. | Une carte par valeur ; catalogue alourdi. |
| C · Coût fixe, effet qui grandit avec le nombre de Sources en jeu | Aucun choix de valeur. | Plus de décision d'investissement ; lie l'effet à une autre ressource. |

## Choix

Le créateur a retenu l'option A le 26 octobre 2026. Les options B et C sont écartées.

Contenu de la décision :

- Le joueur choisit la valeur de X à l'annonce et paie X Essence. Sur la pile, le coût de la carte vaut la valeur choisie pour X ; dans toute autre zone, X vaut 0. X garde sa valeur jusqu'à la fin de la résolution ; l'effet lit cette valeur.
- X vaut au moins 1.
- Seul un Spell peut porter un coût X, pour l'instant.

Points non couverts : une carte dont le coût combine X et une partie fixe (Q-121) ; l'ordre dans lequel le joueur choisit X et les cibles (Q-122). Ces points ne sont pas écrits dans les règles.

Placement : chapitre 213, section 213.1, selon la décision 0116. Ce coût X est distinct d'une valeur X définie par un texte (décision 0216).

À mesurer au playtest J3 : les valeurs de X choisies, les Sources recyclées pour payer un coût X, la part des Spells à coût X jouée avec la valeur 1.

## Conséquences sur les règles

- Chapitre 213 créé : 213.1.1 à 213.1.8.
- Chapitre 202 : 202.1.2, renvoi vers 213.1.1 ajouté, sens inchangé.
- Glossaire : Coût X ajouté ; Coût modifié (renvoi).
