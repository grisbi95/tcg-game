# Lancer les tests

Lance l'agent `verifier` avec la portée « tests », ou la suite nommée en argument (`res://tests/<suite>.gd`) ; les commandes font foi dans `CLAUDE.md` §7. Ne relis pas la sortie brute ici et ne conclus qu'à partir du `Overall Summary` rapporté par `verifier`.
